# AiCAM Smart Intelligent Security - AI Chatbot 🛡️🤖

شات بوت ذكي واحترافي مصمم خصيصاً لهوية شركة **AiCAM** للأمان والمراقبة الذكية، مدعوم بمحرك ذكاء اصطناعي فائق السرعة عبر **Groq API**.

---

## 🎨 الهوية البصرية والألوان المستخدمة (Brand Identity)
تم تطبيق الهوية البصرية الرسمية المرفقة للشركة بدقة متناهية:
* **البرتقالي الأساسي (Primary Orange)**: `#ff773b`
* **الرمادي الفحمي (Charcoal)**: `#2f2f2f`
* **الأبيض (Pure White)**: `#ffffff`
* **شعار وأيقونة AiCAM**: مدمج كشعار متجهي فائق الدقة (SVG) مطابق للتصميم الأصلي، مع النقطة المربعة البرتقالية المميزة فوق حرف `i`.

---

## ⚡ مميزات الشات بوت والواجهة (UI Features)
1. **واجهة مستخدم احترافية وتفاعلية (Modern Responsive UI)**:
   - تصميم جذاب مناسب لشركات التكنولوجيا والأمان مع دعم الوضع الليلي (Dark Mode) والوضع النهاري (Light Mode).
   - متجاوب بالكامل مع الهواتف الذكية، الأجهزة اللوحية، والشاشات الكبيرة.
   - دعم كامل للغة العربية والإنجليزية.
2. **اتصال مباشر وتوليد فوري للردود (Real-time Streaming)**:
   - تدفق مباشر للكلمات في الوقت الفعلي (Server-Sent Events) لتجربة استخدام فائقة السرعة وشبيهة بـ ChatGPT / Claude.
   - عرض خطوات التفكير والتحليل الذكي (Reasoning Steps) مع النماذج المتقدمة مثل `openai/gpt-oss-120b`.
3. **أدوات تحكم متقدمة على كل رسالة**:
   - 📋 نسخ الإجابة بنقرة واحدة (Copy to Clipboard).
   - 🔊 قراءة صوتية بالذكاء الاصطناعي (Text-to-Speech).
   - 🎤 إدخال صوتي بالسؤال عبر الميكروفون (Speech-to-Text).
   - 🔄 إعادة توليد الإجابة (Regenerate Response).
4. **لوحة إدارة المعرفة والتدريب (Knowledge Base & Training Data Manager)**:
   - ميزة مخصصة تتيح لك إضافة أي بيانات أو مواصفات أو أسئلة شائعة ترغب في تدريب الشات بوت عليها في أي وقت لاحقاً.
   - يمكنك لصق النصوص مباشرة، أو استيراد ملفات نصية (`.txt`, `.md`, `.json`).
   - حفظ فوري ينعكس على ردود الشات بوت فوراً دون الحاجة لإعادة تشغيل الخادم!
5. **تعدد النماذج الذكية (Model Switcher)**:
   - `Qwen 3.8 27B` (سريع جداً وممتاز باللغة العربية - الافتراضي).
   - `GPT OSS 120B` (نموذج عملاق فائق الذكاء مع خطوات تفكير تحليلية).
   - `ALLaM 2 7B` (نموذج علام العربي الوطني).
   - `GPT OSS 20B` (خفيف وسريع).

## 🚀 طريقة التشغيل (Quick Start)

### الطريقة الأولى (الأسهل بنقرة واحدة):
- قم بالنقر المزدوج على ملف **`run.bat`**، سيقوم بفتح المتصفح تلقائياً على العنوان:
  `http://localhost:3000`

### الطريقة الثانية (عبر موجه الأوامر):
1. افتح موجه الأوامر (Terminal أو PowerShell) في مجلد المشروع.
2. قم بتشغيل الأمر:
   ```bash
   npm start
   ```
3. افتح المتصفح على:
   ```
   http://localhost:3000
   ```

## 💡 كيفية إضافة بيانات التدريب لاحقاً؟
بما أنك ذكرت أنك سترسل البيانات التي تريد تدريب الشات بوت عليها لاحقاً، لديك خياران في غاية السهولة:
1. **من خلال واجهة الشات بوت مباشرة**:
   - اضغط على زر **"بيانات التدريب والمعرفة"** بأعلى الصفحة.
   - الصق البيانات في تبويب **"بيانات التدريب المخصصة"** أو ارفع الملف، ثم اضغط **"حفظ وتطبيق البيانات"**.
2. **من خلال الملف النصي**:
   - افتح الملف `data/knowledge_base.json` وعدل قسم `custom_training_data` أو أضف تفاصيل منتجاتك.
